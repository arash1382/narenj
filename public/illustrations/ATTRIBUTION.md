# Illustration sources and asset record

- `naranj-brand.webp`: optimized local export of the supplied Naranj logo asset at `narenj/logo/narenj.png`. The supplied mascot and wordmark are preserved. No external modifications or identity substitutions.
- `3d-notebook.webp`: optimized local export of `static/notebook-dynamic-00.png` from [`realvjy/3Dicons`](https://github.com/realvjy/3Dicons), inspected at commit `8884d59e68a7bae0e0e2163af5b6c2ad992c01c8`. The upstream repository's `LICENSE` is CC0 1.0 Universal. It is used as a single supporting learning-object visual and is served locally; there is no hotlink.
- `../avatars/*.webp`: optimized exports of the ten supplied student illustrations under `narenj/illustration/{boy,girl}/`. These are the approved cosmetic avatar options from the project archive; the original source files are preserved.

Exports are WebP to reduce transfer size. The original source files remain untouched in the project archive.

- `learning-world.webp`, `math-exploration.webp`, and `achievement-medals.webp`: original Naranj educational still-life illustrations generated for this project and locally optimized as WebP. The regenerated versions use a seamless ivory studio background (the first drafts' fake transparency checkerboard was discarded).
